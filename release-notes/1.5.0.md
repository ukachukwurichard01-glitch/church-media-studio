# Church Media Studio 1.5.0

## New in this version

- Added OBS Virtual Camera input so the physical camera can be added and controlled in OBS, then received by Church Media Studio for composition.
- Added preacher and Bible layouts: preacher left / Bible right, Bible left / preacher right, Bible above / preacher below, and full-screen preacher.
- The latest Bible verse sent live can remain alongside the preacher in the selected composition layout.
- Added a saved Church Service Planner with a reusable Sunday service order, editable items, estimated duration, and one-click preparation for live output.
- Added 15 animated 3D-style motion backdrop designs for countdown and presentation output.
- Added online Bible translation selection for Igbo, Hausa, and Yoruba where a complete translation is available from the connected public Bible library. The offline KJV remains available.
- Lower thirds are now suppressed automatically on Bible and hymn/song slides. They can appear for a live preacher and eligible presentation content when enabled.
- Updated the application version to 1.5.0 and added a Windows CI build check.

## Camera setup

1. Add the physical camera in OBS as a Video Capture Device.
2. Start OBS Virtual Camera.
3. In Church Media Studio, open Live Composition and select OBS Virtual Camera.
4. Choose the preacher/Bible layout and send the live preacher composition.
5. Start Church Media Studio NDI output and add CHURCH MEDIA STUDIO as an NDI Source in OBS.

## Notes

- The Igbo, Hausa, and Yoruba Bible translation feeds require an internet connection. The KJV remains offline.
- The new source code is version 1.5.0. A Windows installer release must include the matching NSIS setup file and electron-updater metadata (latest.yml and blockmap) before the in-app updater can offer it.
